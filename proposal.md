# WPI Schedule Formatter and Sharing Tool

In our group, Kyle Plosky maintains a Discord bot that allows the user to import their WPI schedule from workday and display it in an easy to digest form. For this project, we plan on working together to rebuild this idea into a more developed form as a web application to improve accessibility, design, and features.

Users will be able to upload a copy of their WPI schedule (which can be exported from Workday as an Excel file). The application will then display the user’s course schedule for a specified term, which can then be saved as an image if desired. Users will optionally be able to log in, in which case the application will save all of the user's courses to the database and provide a link to share their schedule with others.

## Things we would like to implement if time allows include:

Allowing users to have an allowlist of other users to be able to access their schedule at any time.
