# WPI Schedule Formatter and Sharing Tool

- Noah Gaskill
- Richard Newman
- James Ostermiller
- Kyle Plosky

---

In our group, Kyle Plosky maintains a Discord bot that allows the user to import their WPI schedule from workday and display it in an easy to digest form. For this project, we plan on working together to rebuild this idea into a more developed form as a web application to improve accessibility, design, and features.

Users will be able to upload a copy of their WPI schedule (which is exported from Workday as an Excel file), though they may optionally enter it manually. The application will then visually display the user’s course schedule for any selected term for which they have uploaded their data, including information such as time, class name, professor, and location. These schedules can further be saved as an image if desired. Users will optionally be able to log in, in which case the application will save all of the user's courses to the database and provide a link to share their schedule with others.

## Things we would like to implement if time allows include:

- Allowing users to have an allowlist of other users to be able to access their schedule at any time.
- Implement OAuth
